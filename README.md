## ⭐ Essential Software Stack

A curated list of highly recommended, mostly FOSS (Free and Open-Source Software) applications for a clean, efficient, and private Windows/Linux setup.

### Security & Privacy

- **[SimpleWall](https://github.com/henrypp/simplewall)** — Lightweight, powerful Windows Filtering Platform (WFP) firewall.
- **[KeePassXC](https://keepassxc.org/)** — Offline, cross-platform password manager.
- **[Aegis Authenticator](https://getaegis.app/)** — Secure, free, and open-source 2FA authenticator for Android with encrypted backups.
- **[Mullvad VPN](https://mullvad.net/)** — Privacy-first VPN that requires no personal data (not even an email) to create an account.
- **[ProtonVPN](https://protonvpn.com/)** — Highly secure, open-source VPN based in Switzerland with a strict no-logs policy.
- **[Amnezia VPN](https://amnezia.org/)** — Client for deploying and connecting to self-hosted, protocol-obfuscated VPNs on your own VPS.
- **[Tor Browser](https://www.torproject.org/)** — The standard for network anonymization.

### Network & Web

- **[LibreWolf](https://librewolf.net/)** — A custom version of Firefox focused on privacy and security out of the box.
- **[Chromium](https://www.chromium.org/)** — Open-source foundation for a clean web browsing experience.
- **[MobaXterm](https://mobaxterm.mobatek.net/)** — Ultimate remote computing toolbox (SSH, X11, RDP, SFTP).
- **[LocalSend](https://localsend.org/)** — Drop-in replacement for AirDrop; securely share files over local networks.
- **[qBittorrent](https://www.qbittorrent.org/)** — Ad-free, lightweight, open-source torrent client.

### System Management & Virtualization

- **[MAS (Microsoft Activation Scripts)](https://massgrave.dev/)** — Open-source Windows and Office activator using clean HWID/Ohook methods, with official ISO mirrors and troubleshooting docs.
- **[Win11Debloat](https://github.com/Raphire/Win11Debloat)** — Essential script to remove Windows telemetry and bloatware.
- **[UniGetUI](https://github.com/marticliment/WingetUI)** — Graphical interface for CLI package managers (Winget, Scoop, Chocolatey).
- **[VirtualBox](https://www.virtualbox.org/)** — Accessible and powerful local virtualization.
- **[Ventoy](https://www.ventoy.net/)** — Create bootable USB drives simply by copying ISO files.
- **[Rescuezilla](https://rescuezilla.com/)** — FOSS bare-metal restore and disk cloning.
- **[GParted](https://gparted.org/)** — The industry-standard partition management tool.

### Utilities & Productivity

- **[Everything](https://www.voidtools.com/)** — Instantaneous local file search for Windows.
- **[PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/)** — System utilities for power users (includes OCR, window management, etc.).
- **[7-Zip](https://www.7-zip.org/)** — High-compression file archiver.
- **[ShareX](https://getsharex.com/)** — The ultimate screen capture, file sharing, and productivity tool.
- **[DeepL](https://www.deepl.com/)** — Highly accurate, AI-powered translator that produces exceptionally natural-sounding text.
- **[Prompt Cowboy](https://www.promptcowboy.ai/)** — A prompt generation tool that transforms rough ideas into structured, high-performing prompts for major language models.

### Media & Knowledge

- **[Obsidian](https://obsidian.md/)** — A private, flexible brain for note-taking using local Markdown files.
- **[Koodo Reader](https://koodo.960960.xyz/)** — Modern, cross-platform ebook manager and reader.
- **[MPC-HC](https://github.com/clsid2/mpc-hc)** — Extremely lightweight classic media player.
- **[Nomacs](https://nomacs.org/)** — Fast, open-source image viewer with RAW support.
- **[OBS Studio](https://obsproject.com/)** — Professional-grade video recording and live streaming.

## 🕵️‍♂️ Privacy & Anonymity

*Tools and guides to reclaim your digital footprint.*

- **[Privacy Guides](https://www.privacyguides.org/)** — Independent, community-driven resource providing recommendations for privacy-respecting tools and OS hardening.
- **[Messaging Apps Privacy Matrix](https://privacyspreadsheet.com/messaging-apps)** — Detailed comparison of secure messaging protocols.
- **[Terms of Service; Didn't Read](https://tosdr.org/)** — Transparent grading of website terms of service and privacy policies.
- **[Search Engine Party](https://searchengine.party/)** — Deep-dive comparison of search engine tracking behaviors.
- **[The Hitchhiker’s Guide to Online Anonymity](https://anonymousplanet.org/guide.html)** — An extensive, paranoid-level guide to digital anonymity.

## 🛡️ Security & Intelligence

- **[VirusTotal](https://www.virustotal.com/gui/)** — Analyze suspicious files, domains, and IPs across dozens of antivirus engines.
- **[ProtonMail](https://mail.proton.me/)** — End-to-end encrypted email service based in Switzerland.
- **[YarrList](https://github.com/yarrlist/YarrList)** — A comprehensive index of useful sites and trackers.

## 📖 Open Knowledge & Archives

- **[Anna's Archive](https://annas-archive.org/)** — The world's largest open-source digital library search engine.
- **[Z-Library](https://z-library.sk/)** — Massive repository for academic texts, articles, and ebooks.

## 🔍 Software Discoverability & Package Managers

- **[AlternativeTo](https://alternativeto.net/)** — Crowdsourced software recommendations to replace proprietary or bloated apps.
- **[winget.run](https://winget.run/)** — A fast, easily searchable web UI for exploring Windows Package Manager (Winget) packages.
- **[winstall.app](https://winstall.app/)** — Visually select apps and generate batch Winget installation scripts directly from your browser.
